## 🎮 Gameplay & Features

- 🐘 **Cyber Elephant Protagonist**: Run, duck, jump, and double-jump across a terminal cyberspace.
- 🌧️ **Dynamic Matrix Digital Rain**: Real-time falling katakana / green binary stream on HTML5 Canvas.
- ⚡ **Hacker Powerups**:
  - 🛡️ **SHIELD**: Immune to firewalls and glitch colliders.
  - 🚀 **JETPACK**: Soar through the sky above obstacles.
  - ⚡ **TURBO**: High-speed score multiplier with particle trails.
- 🎨 **Elephant Skin Selector**:
  - 🟢 **Matrix Edition**: Cyber green aesthetic.
  - 🔵 **Neon Cyan**: Futuristic cyber aesthetic.
  - 🟡 **Golden Root**: Unlockable elite master skin.
- 🔊 **Synthesized Web Audio Engine**: Zero external audio files! Every jump, double-jump, powerup chime, and explosion is synthesized on the fly using the browser's native AudioContext.
- 📺 **Retro CRT Overlay**: Scanline rendering and glowing neon phosphors for genuine arcade nostalgia.
- 📱 **Fully Responsive**: Fluid scaling with desktop keyboard controls and mobile touch gestures.

## 🕹️ Controls

| Action | Keyboard | Mobile / Touch |
|:---|:---:|:---:|
| **Jump** | <kbd>SPACE</kbd> / <kbd>▲ Up</kbd> / <kbd>W</kbd> | Tap screen |
| **Double Jump** | Press <kbd>SPACE</kbd> / <kbd>▲ Up</kbd> twice in air | Double Tap |
| **Duck / Slide** | <kbd>▼ Down</kbd> / <kbd>S</kbd> | Swipe Down |
| **Pause / Resume** | <kbd>P</kbd> | Pause Button |
| **Mute / Unmute** | <kbd>M</kbd> | Audio Button |

## 🛠️ Tech Stack

- **Canvas Rendering**: HTML5 2D Canvas Engine with 60 FPS requestAnimationFrame loop.
- **Styling**: Vanilla CSS3, CSS Grid/Flexbox, CRT Scanline shader simulation, Scanline animations.
- **Game Logic**: Pure Vanilla Object-Oriented JavaScript (ES6+).
- **Audio**: Web Audio API (OscillatorNode, GainNode, White Noise Buffer synthesis).

## 🚀 Getting Started

### Play Instantly
Simply clone this repository and open index.html in any modern web browser:

`ash
# Clone the repository
git clone https://github.com/Sagarchaudhary91187/Cyber-Elephant-Runner.git

# Navigate into the project folder
cd Cyber-Elephant-Runner

# Open in your browser (Windows)
start index.html
`

Or run with any local dev server:
`ash
npx serve .
`
